# Memory — durable decisions & facts

agents and humans should not have to re-derive. Each file is one decision/fact
(ADR-style). Keep them short and current; if a decision is reversed, update the
file rather than deleting the history of *why*.

These are loaded as context for AI agents working in the repo — high signal only.
