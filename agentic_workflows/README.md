# Agentic Workflows

The vertical orchestration box cutting across layers to orchestrate multi-agent operations, thought loops, and unified registries.

## Target Structure & Subdirectories

- **`primitives/`**: Base ADK (Agent Development Kit) agent templates, agent memories, and thinking loops.
- **`orchestrators/`**: MoE-F (Mixture-of-Experts for Finance) coordinators and cross-box agent dispatchers.
- **`tools/`**: Global tool registries accessible by agents.

## Purpose & Architectural Rule

This layer manages the **cross-cutting orchestration logic**. It brings together data connections (from `data_prep`), technical filters/indicators (from `model_library`), backtest execution (from `strategy_testing`), and risk controls (from `risk_management`) into a coherent cognitive process.
