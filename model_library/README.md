# Model Library (BOX 2)

Houses agentic AI configurations, traditional machine learning models, and mathematical technical signals.

## Target Structure & Subdirectories

- **`agentic_ai/`**: Stochastic filtering, MoE expert configs, and ADK agent blueprints.
- **`ml_zoo/`**: Traditional machine learning models (XGBoost, Hidden Markov Models, probabilistic filters).
- **`technical/`**: Quantitative indicators and atomic signal math (e.g. sma_crossover_signal).

## Purpose & Architectural Rule

This box serves as the predictive engine of the system. It contains the deterministic math and probabilistic models that agents use to calculate buy/sell decisions, regime shifts, and market transitions.
