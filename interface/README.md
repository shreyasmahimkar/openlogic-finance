# Interface (BOX 6)

Subdivided into notebooks (research templates), command-line interfaces (cli), and Streamlit dashboards to represent three distinct UX targets.

## Target Structure & Subdirectories

- **`notebooks/`**: Notebook-as-a-Service environments, research templates, and tutorials.
- **`cli/`**: Command-line interface agents and dev terminal interactive tools.
- **`streamlit/`**: Streamlit dashboards, multi-agent monitoring UI, and strategy visualizers.

## Purpose & Architectural Rule

This box provides all the frontend, plotting, and developer interfaces. It connects developers, quantitative researchers, and users to the underlying MAS (Multi-Agent System) execution pipeline.
